# Project Governance and Agent Guidance

Within the project's documentation, this document is the authoritative, highest-priority source of project-specific guidance. It defines how the project owner and contributors plan work, organize the project, and communicate objectives, requirements, and decisions to AI agents.

The project owner and contributors maintain and update this document as the project evolves. It records the project's purpose, scope, working principles, and operating rules, establishing the requirements agents must follow when contributing to the project's development.
